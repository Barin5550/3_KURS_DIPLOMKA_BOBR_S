# УСТАНОВКА «МАРШРУТА» НА IPHONE

Напрямую поставить своё приложение на iPhone можно только через платный аккаунт разработчика Apple и компьютер Mac. Поэтому используется бесплатный способ: программа Sideloadly на компьютере с Windows подписывает приложение вашим Apple ID и ставит его на iPhone по кабелю. Бесплатная подпись действует 7 дней, потом установку нужно повторить (раздел «Через 7 дней»).

Что понадобится:

- компьютер с Windows и интернетом;
- iPhone с iOS 15 или новее;
- кабель, которым iPhone заряжается от компьютера;
- ваш Apple ID (тот, под которым вы вошли на iPhone) и пароль от него.

## Шаг 1. Скачать файл приложения

1. Открыть [страницу сборок «Сборка и тесты»](https://github.com/Barin5550/3_KURS_DIPLOMKA_BOBR_S/actions/workflows/build.yml) (войти в GitHub, если попросит).
2. Нажать на верхний запуск с зелёной галочкой.
3. Прокрутить страницу вниз до раздела **Artifacts** и нажать **marshrut-ios**. Скачается архив `marshrut-ios.zip`.
4. Открыть папку «Загрузки», нажать на архив правой кнопкой мыши, выбрать **«Извлечь все…»**, затем **«Извлечь»**. В открывшейся папке будет файл `marshrut-ios.ipa`.

Когда на странице Releases публикуется новый релиз, файл `marshrut-ios.ipa` прикладывается к нему автоматически, и его можно скачать оттуда.

## Шаг 2. Установить iTunes, iCloud и Sideloadly

Sideloadly работает только с iTunes и iCloud, скачанными с сайта Apple. Версии из Microsoft Store не подходят.

1. Если iTunes или iCloud уже установлены из Microsoft Store, удалить их: **Пуск → Параметры → Приложения**, найти iTunes, нажать **«Удалить»**; то же для iCloud.
2. Скачать и установить [iTunes с сайта Apple](https://www.apple.com/itunes/download/win64).
3. Скачать и установить [iCloud с сайта Apple](https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe).
4. Скачать и установить [Sideloadly](https://sideloadly.io/SideloadlySetup64.exe).
5. Если установщик попросит перезагрузить компьютер, перезагрузить.

## Шаг 3. Подключить iPhone

1. Разблокировать iPhone и подключить его к компьютеру кабелем.
2. На iPhone появится вопрос **«Доверять этому компьютеру?»**. Нажать **«Доверять»** и ввести код-пароль iPhone.

## Шаг 4. Установить приложение

1. Открыть Sideloadly.
2. В поле **iDevice** должно появиться имя вашего iPhone. Если его нет, переподключить кабель.
3. В поле **Apple account** ввести свой Apple ID (адрес почты).
4. Перетащить файл `marshrut-ios.ipa` в окно Sideloadly, на большой значок **IPA** слева (или нажать на этот значок и выбрать файл).
5. Нажать **Start**. Ввести пароль от Apple ID. Если на iPhone придёт код подтверждения, ввести его в Sideloadly.
6. Подождать несколько минут, пока Sideloadly не сообщит, что установка завершена. На экране iPhone появится значок «Маршрут».

## Шаг 5. Разрешить запуск на iPhone

1. **Режим разработчика** (iOS 16 и новее): **Настройки → Конфиденциальность и безопасность**, в самом низу **«Режим разработчика»** → включить → **«Перезагрузить»**. После перезагрузки нажать **«Включить»** и ввести код-пароль.
2. **Доверие вашему Apple ID**: **Настройки → Основные → VPN и управление устройством**, в разделе «Приложение разработчика» нажать на свой Apple ID → **«Доверять»** → ещё раз **«Доверять»**.
3. Открыть «Маршрут». При первом включении напоминания iPhone спросит разрешение на уведомления: нажать **«Разрешить»**.

## Через 7 дней

Когда «Маршрут» перестанет открываться, нужно повторить шаги 3 и 4: подключить iPhone кабелем, открыть Sideloadly и нажать **Start** с тем же файлом. Приложение перед этим не удалять, тогда план, заметки и вход сохранятся. Перед защитой лучше переустановить приложение накануне, чтобы срок подписи точно не закончился.

## Если не получается

- Sideloadly не видит iPhone: проверить, что iTunes установлен с сайта Apple, разблокировать iPhone и переподключить кабель.
- Sideloadly долго висит на входе в Apple ID: закрыть iTunes и Sideloadly, открыть Sideloadly снова и повторить шаг 4.
- На бесплатном Apple ID одновременно может быть установлено не больше трёх таких приложений. Если появилась ошибка о лимите, удалить с iPhone другое приложение, поставленное через Sideloadly.
