# Презентации к защите

| Файл | Для чего | Слайдов |
|---|---|---|
| `Маршрут_итоговая_защита.pptx` (+ `.pdf`) | Итоговая защита курсового проекта: тема, аналоги, архитектура «приложение + сервер API», алгоритм, сценарий 1 семестра, функционал 2 семестра, база данных и CRUD через API, демонстрация с журналом сервера, профиль и безопасность, UI/UX, тесты, курсовая и сборки | 17 |
| `Маршрут_защита_концепции.pptx` (+ `.pdf`) | Защита концепции (этап 1): 5 минут, 5–7 слайдов, критерии «тема», «стек и архитектура», «UI/UX и прототип» | 7 |

Текст выступления лежит в заметках докладчика к каждому слайду (в PowerPoint: «Вид → Заметки»).

## Пересборка

Скриншоты берутся из `docs/coursework/screenshots/`, иконка — из `tool/icons/app_icon_1024.png`.

```bash
python3 docs/presentation/tool/prep.py docs/coursework/screenshots <папка>/img
cp tool/icons/app_icon_1024.png <папка>/img/icon.png
# build.js кладётся рядом с img/, нужен pptxgenjs и apply_theme.js из навыка pptx
node build.js <папка вывода>
```
