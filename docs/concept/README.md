## Как подготовить презентацию

1. Скопировать текст из блоков «На слайде» в PowerPoint или Google Slides (по одному блоку на слайд).
2. Схемы Mermaid вставить картинкой: открыть [mermaid.live](https://mermaid.live), вставить код, экспортировать PNG.
3. Речь из блоков «Речь» прочитать вслух с таймером: цель — 4,5 минуты.
