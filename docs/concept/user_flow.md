# User flow приложения «Маршрут»

Схема показывает основные экраны и переходы между ними. Диаграммы в формате Mermaid отображаются на GitHub и в большинстве редакторов Markdown (например, VS Code с расширением Markdown Preview Mermaid Support).

## 1. Общий сценарий

```mermaid
flowchart TD
  S([Splash<br/>логотип, проверка сессии]) -->|сессия есть, план есть| H
  S -->|сессия есть, плана нет| O1
  S -->|сессии нет| L

  L[Вход<br/>email + пароль] -->|«Нет аккаунта?»| R[Регистрация<br/>имя, email, пароль, повтор]
  R -->|«Уже есть аккаунт»| L
  R -->|успешно| O1
  L -->|ошибка| L
  L -->|успешно, план есть| H
  L -->|успешно, плана нет| O1

  subgraph ONB[Онбординг — создание плана]
    O1[Шаг 1. Направление<br/>Flutter / Python / Английский / Алгоритмы] --> O2[Шаг 2. Диагностический тест<br/>или «Я новичок»]
    O2 --> O3[Шаг 3. Расписание<br/>часы в неделю, дни, дедлайн]
    O3 --> O4[Предпросмотр плана<br/>темы, дата окончания,<br/>предупреждение о дедлайне]
  end
  O4 -->|«Начать»| H

  subgraph SHELL[Нижняя навигация]
    H[Главная<br/>прогресс, задачи на сегодня]
    P[План<br/>занятия по дням, поиск, фильтры]
    T[Темы<br/>каталог, избранное, свои темы]
    ST[Статистика<br/>графики, история]
    PR[Профиль<br/>данные, настройки, выход]
  end
  H <--> P
  P <--> T
  T <--> ST
  ST <--> PR

  H --> SD[Занятие<br/>описание темы, материалы]
  P --> SD
  SD --> POM[Pomodoro-таймер]
  SD --> N[Заметки по теме]
  T --> TD[Карточка темы]
  T --> CT[Своя тема<br/>создать / изменить / удалить]
  P --> PL[Мои планы<br/>несколько планов, переименование, удаление]
  PL --> O1
  P -->|есть пропуски| RP[Перестроить план]
  PR --> EP[Редактировать профиль]
  PR --> CP[Сменить пароль]
  PR --> NL[Все заметки]
  PR -->|«Выйти»| L
```

## 2. Правила доступа (go_router redirect)

```mermaid
flowchart LR
  A[Переход на маршрут] --> B{Пользователь<br/>авторизован?}
  B -->|нет| C{Маршрут открытый?<br/>/splash, /login, /register}
  C -->|да| D[Показать экран]
  C -->|нет| E[Перенаправить на /login]
  B -->|да| F{Маршрут /login<br/>или /register?}
  F -->|да| G[Перенаправить на /home]
  F -->|нет| D
```

После нажатия «Выйти» сессия удаляется, срабатывает `redirect`, и любой закрытый экран (например, `/home` или `/profile`) становится недоступен до повторного входа.

## 3. Сценарий для демонстрации (1 семестр)

```mermaid
sequenceDiagram
  actor U as Студент
  participant App as Маршрут
  U->>App: Запуск
  App-->>U: Splash (логотип, 1,5 с)
  App-->>U: Экран входа
  U->>App: «Нет аккаунта? Зарегистрироваться»
  U->>App: Пустая форма → «Создать аккаунт»
  App-->>U: Ошибки под полями
  U->>App: Корректные данные
  App-->>U: Онбординг: направление → тест → расписание
  App-->>U: Главная: прогресс 0 %, задачи на сегодня
  U->>App: Отметить занятие выполненным
  U->>App: Вкладки: План → Темы → Статистика → Профиль
  U->>App: «Выйти»
  App-->>U: Экран входа, закрытые экраны недоступны
  U->>App: Вход с неверным паролем
  App-->>U: «Неверный email или пароль»
  U->>App: Вход с верным паролем
  App-->>U: Главная
```
